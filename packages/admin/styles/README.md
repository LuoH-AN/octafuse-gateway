# 管理后台 Material 主题

参考桌面歌词 Android 应用的 Material 3 外观，采用黑白灰配色，用表面明度、字重和不同圆角区分操作与内容层级。安卓 Compose 组件无法在 React 中运行，因此这里复用后台现有控件，仅实现网页主题；未复制安卓组件源码，也没有新增运行时依赖。

- `material-preset.ts`：颜色、字体、圆角与阴影。现有 `gray` / `slate` 对应中性色，`blue` 等装饰色对应单色主调；错误、警告和成功状态保留语义色。
- `material.css`：以 `admin-material` 为作用域，提供公共控件适配和带 `md-` 前缀的布局样式。当前为浅色主题，不依赖外部字体服务。
- `MaterialInteractions.tsx`：委托处理按钮、导航和展开控件的按压波纹；不拦截默认事件，滚动或取消触摸时清除波纹，遵守减少动效设置。侧栏的加载指示读取 Next.js 的实际导航状态。
- 接入点：`tailwind.config.ts` 引入预设，`app/layout.tsx` 在 `globals.css` 之后引入样式，为 `body` 添加作用域，并挂载交互反馈。公共筛选、视图切换和设置卡片使用 `md-` 样式类名。

同步上游时，保留上述接入点与布局类名；主题修改尽量留在此目录。新增页面使用现有颜色和控件类名即可沿用主题。若上游改用了另一套组件或类名，再调整这里的适配规则。不要使用 Git 的 `ours` 合并策略跳过上游功能更改。

登录提交在原表单内显示进度，防止页面跳成全屏加载。仪表盘趋势图使用灰阶与不同线型区分数据系列。鉴权接口与业务数据处理逻辑保持原有契约。
