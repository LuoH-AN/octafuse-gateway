# 管理后台 Material 主题

参考桌面歌词 Android 应用的 Material 3 外观，使用 `#2e7d32` 为种子色的森林绿柔和配色。安卓 Compose 组件无法在 React 中运行，因此这里复用后台现有控件，仅实现网页主题；未复制安卓组件源码，也没有新增运行时依赖。

- `material-preset.ts`：颜色、字体、圆角与阴影。现有 `gray` / `slate` 对应中性色，`blue` 对应主题主色；状态色与供应商品牌图案保留各自配色。
- `material.css`：以 `admin-material` 为作用域，提供公共控件适配和带 `md-` 前缀的布局样式。当前为浅色主题，不依赖外部字体服务。
- 接入点：`tailwind.config.ts` 引入预设，`app/layout.tsx` 在 `globals.css` 之后引入样式，并为 `body` 添加作用域。四个布局组件只添加样式类名。

同步上游时，保留上述接入点与布局类名；主题修改尽量留在此目录。新增页面使用现有颜色和控件类名即可沿用主题。若上游改用了另一套组件或类名，再调整这里的适配规则。不要使用 Git 的 `ours` 合并策略跳过上游功能更改。

重点检查登录页、桌面与手机导航、语言菜单、表单焦点、列表与卡片切换、宽表格的固定列，以及弹窗内滚动。Material 样式不改变导航、鉴权、接口与数据处理逻辑。
