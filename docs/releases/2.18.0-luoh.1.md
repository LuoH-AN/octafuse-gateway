## 本次更新

自有部署升级至上游 v2.18.0，并同步 main 截至 5833b53b 的更新。此版本发布于 LuoH-AN/octafuse-gateway。

## 变更内容

- 支持 MCP OAuth 访问令牌、粘性绑定查看和解绑、流式响应头与首事件超时、Gemini 历史签名修复。
- 同步上游模型目录、Octafuse Logo 和 Command Code 月度额度查询更新。
- 保留本地 Responses 工具续轮修复：reasoning 项缺失或为 null 的 summary 补为空数组，覆盖请求、JSON 响应和 SSE。

## 升级说明

- 先备份数据库，按顺序应用 D1 迁移 0034、0035，再更新同版本 Proxy 和 Admin。
- OAuth 默认关闭；新模型目录需要手工导入，已导入的模型和供应商保持现有配置。
- 完整上游升级说明见 v2.18.0 发布说明；本版本的 Cloudflare 制品由仓库 Actions 构建并校验。
